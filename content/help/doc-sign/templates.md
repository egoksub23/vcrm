A template is a document prepared once, with its pages, fields, roles and starting choices. You use it again and again, so a new document takes a minute.

## Before you start

Anyone who can see Doc Sign can look at templates. To create or change them you need permission to manage templates. To use one for a new document you need permission to send.

## Open the library

Click **Doc Sign**, then **Templates**. Each row shows the name, category, status, how many versions it has, when it was last changed, and any tags. Use the search box and the **Category** and **Status** filters to find one.

## Create a template

1. Click **New template**.
2. Drop a file in the box, or choose one. A PDF, a Word file or an image (JPG or PNG), up to 25 MB.
3. Optionally give it a name and a category. Without a name, the file name is used.
4. Click **Create and open editor**.

The editor opens with the pages. Place the fields and roles, and set the defaults. See [Prepare the fields](/help/doc-sign/prepare-fields). A new template is a **Draft**.

If something is wrong with the file, the message says what, and what to do.

| Message | What to do |
|---|---|
| The file is empty, too large or not a supported type | Choose a PDF, a Word file or an image up to 25 MB |
| The Word file has macros or a password | Save it without macros, or remove the password, or save it as a PDF |
| Word conversion is not available right now | Upload a PDF instead. Your admin can turn conversion on |
| The file takes too long to convert, or is too long | Save it as a PDF and upload that |

## Save a prepared document as a template

If you already prepared a draft document and want to keep its fields, save it as a template from the editor. The file, the fields, the roles and your choices are copied into a new template.

## Statuses

| Status | What it means |
|---|---|
| **Draft** | Being prepared. It cannot be used for a document yet. |
| **Active** | Ready. It shows in **Use a template** when you start a document. |
| **Archived** | Put away. It is hidden from new documents but nothing is lost. |

A draft needs at least one role and one field before it can be made active. Click **Make active** on its row. If it is not ready, the message tells you what to add.

## Use a template

Click **Use this template** on an active template, or choose **Use a template** when you start a new document. The draft starts with the template's fields, roles and defaults. See [Send a document for signature](/help/doc-sign/send-a-document).

## Versions

Editing a template saves a new **version**. Documents already sent keep the exact version they were sent with, so what the signers saw never changes. The library shows how many versions each template has.

## Different terms, different templates

If another group of customers has other fees or other clauses, make another template. Click the copy button on the original's row to **Duplicate** it. The copy is a new draft with the same file, fields and roles, and a name ending in "(copy)". Rename it and change what differs.

## Archive, restore and delete

- **Archive** hides a template without losing it. **Restore** brings it back as a draft, so check it and make it active again.
- **Delete** removes the template and its versions for good. Documents already made from it keep their own copy and do not change. If you might need it again, archive it instead.

> [!NOTE]
> A template that came from an add-on shows an **Add-on** label. When you edit it, it also shows **Customised**, and later add-on installs leave it alone. See [Categories and add-ons](/help/doc-sign/categories-and-add-ons).

## Tips

- Name templates so people can tell them apart: "Merchant Agreement (BM)" is clearer than "Agreement 2".
- Put each template in a category so the filters are useful.

## Common mistakes

- **Expecting a change to reach documents already sent.** It does not. Only new documents use the new version.
- **Deleting a template to hide it.** Archive it instead.
