If you use the same filters every day, save them as a view. If a lot of chats need the same change, do it in one go.

## Before you start

Saving personal views and all bulk actions need permission to manage conversations. If you do not have it, these buttons are greyed out with the tooltip "Read-only — your role can't manage conversations". See [Roles and permissions](/help/getting-started/roles-and-permissions).

## Saved views

A view remembers:

- The first drop-down (All, Mine, Unassigned, Unread, Open, Pending, Closed).
- Tags, Labels, Company and Team.
- The channels you ticked.
- The priority filter.
- The sort order (Recent or Priority).

It does **not** remember the words in the search box.

### Save a view

1. Set up the filters you want above the conversation list.
2. Press the bookmark button (**Views**).
3. Press **+ Save current filters as a view**.
4. Type a name in **View name**.
5. Press **Save**.

You see "Saved view" and the name. Some people also see a box **Share with the whole team**. That is for views the whole team can use. By default only admins can share views.

![The Views menu open, with one shared view marked by a people icon and the option to save the current filters](/help/img/views-and-bulk-actions-01-views-menu.png)

### Use a view

Press the bookmark button and click the view's name. It replaces your current filters. If the view is about email channels, Vircle CRM moves you to the **Emails** tab.

Shared views have a small people icon.

### Delete a view

Point at a view in the menu and press the bin button. You can delete your own views. Shared views can only be deleted by people who are allowed to share.

### Clear filters

When you have tag, label, company, team or priority filters on, small chips appear under the filters. Press a chip to remove that one, or **Clear all** to remove all of them (a channel filter is removed too). **Clear all** does not change the first drop-down.

## Bulk actions

Use these when many chats need the same change, for example after an incident.

1. Press the checklist button (**Select conversations for a bulk action**) above the list. Tick boxes appear.
2. Click the chats you want. Clicking a row ticks it instead of opening it.
3. A bar appears: "3 selected". Press **Select all** to tick every chat now shown in the list. Press **Clear all** to untick everything.
4. Choose an action from the bar.

![The bulk actions bar showing the number selected, Assign, Apply label, mark as read, mark as unread and Close](/help/img/views-and-bulk-actions-02-bulk-bar.png)

To leave selection mode without doing anything, press the checklist button again.

### The actions

| Action | What it does |
|---|---|
| **Assign** | Choose a teammate, or **Unassign**. All the selected chats go to that person, and they get an alert for each chat. There is no hand-over note box. |
| **Apply label** | Choose a label. It is added to every selected chat. The list shows only labels (topics). Tags, which describe a type of customer, are not offered here, and the app refuses to attach one to a chat. |
| **Mark as read** (open envelope) | Clears the unread number. |
| **Mark as unread** (closed envelope) | Puts an unread mark back. |
| **Close** | Opens **Close N conversations**. |

### Close many chats

1. Press **Close**.
2. Write one closing note. It is saved on each chat. The box says: "One closure note is required — it's saved on each of the N conversations."
3. Press **Close**.

Chats that are already closed are skipped. The AI note draft is not offered for a bulk close. To see the result, read the message that pops up: for example "Closed 5 conversations".

### When something goes wrong

- "Updated 4 of 5 conversations — some failed": most worked. Selection mode stays on so you can try again.
- "Nothing to change — they're already in that state": every selected chat was already read, unread or closed as you asked.

When every chat succeeds, selection mode switches off by itself.

## Tips

- Bulk actions only affect chats shown in the current tab and filter. Filter first, then **Select all**.
- Check the count in "N selected" before you press **Close**. A closing note is shared, so write it in general words.

## Common mistakes

- **Saving a view and expecting your search words to be saved.** Only filters and sorting are saved.
- **Pressing Select all with no filter and then Close.** That closes every chat in the tab.
- **Expecting a hand-over note on bulk Assign.** Use a single Assign, or add a comment on each chat.
