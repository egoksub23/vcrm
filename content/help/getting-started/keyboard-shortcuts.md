Vircle CRM has a small set of keyboard shortcuts. They save the most time when you reply to customers. There are no shortcuts to jump between pages or to assign or close a chat, so you use the mouse for those.

> [!NOTE]
> On a Mac, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>. Both work.

## The reply box in the Inbox

These work in the box where you type to a customer, and in the internal comment box.

| Keys | What happens |
|---|---|
| <kbd>Enter</kbd> | Sends the message (or posts the comment). |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | Starts a new line without sending. |
| <kbd>:</kbd> and two letters, for example `:smi` | Shows emoji suggestions. |
| <kbd>↑</kbd> <kbd>↓</kbd> | Moves through the emoji suggestions. |
| <kbd>Enter</kbd> or <kbd>Tab</kbd> | Inserts the highlighted emoji. |
| <kbd>Esc</kbd> | Closes the emoji suggestions. |
| `:smile:` typed in full | Turns into the emoji when you type the closing colon. |
| `/kb` on its own, or `/kb refund` | Opens the Knowledge article list. Nothing else may be in the box. |
| <kbd>Enter</kbd> while the `/kb` list is open | Inserts the first article shown, instead of sending. |
| <kbd>Esc</kbd> while the `/kb` list is open | Closes it. |
| <kbd>Esc</kbd> while the **Snippets** or **Knowledge** panel is open | Closes the panel. |

The emoji shortcut does not trigger for times such as 10:30 or for web links.

In an **email** reply, the box is an editor. <kbd>Enter</kbd> starts a new line there, and the `:` emoji shortcut is not available (use the smiley button in the editor toolbar). Press the **Send** button (the paper plane) to send.

### Mentioning a teammate in a comment

In **Comment** mode, type <kbd>@</kbd> and the start of a name.

| Keys | What happens |
|---|---|
| <kbd>@</kbd> and a few letters | Shows matching teammates. |
| <kbd>Enter</kbd> or <kbd>Tab</kbd> | Picks the first name in the list. |
| <kbd>Esc</kbd> | Closes the list. |

You can also click a name in the list.

### Captions on photos, videos and documents

After you attach a file, type a caption and press <kbd>Enter</kbd> to send the file.

## Notes and other text boxes

| Where | Keys | What happens |
|---|---|---|
| **Session notes** (a note about the customer) | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Adds the note. <kbd>Enter</kbd> on its own starts a new line. |
| Editing a session note | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> or <kbd>Esc</kbd> | Saves, or cancels. |
| **Contact fields** in the right column (name, phone, email and so on) | <kbd>Enter</kbd> or <kbd>Esc</kbd> | Saves, or cancels the change. |
| Public comment replies (Comments tab) | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Sends the reply. |
| Ticket comments | <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Saves the comment. |

## Photos and videos

When you open a photo or video from a chat, the arrow keys <kbd>←</kbd> and <kbd>→</kbd> move to the previous or next photo or video in that chat. <kbd>Esc</kbd> closes the viewer.

## The emoji picker

Open it with the smiley button next to the reply box. Use the arrow keys, <kbd>Home</kbd> and <kbd>End</kbd> to move between emoji. Type in the search box to find an emoji by name.

## The menu on a phone

<kbd>Esc</kbd> closes the sidebar menu when it is open on a small screen.

## The User Guide

Inside the User Guide, press <kbd>Ctrl</kbd> + <kbd>K</kbd> or <kbd>/</kbd> to search.

## Tips

- Turn on the habit of `:` for emoji. It is faster than opening the picker.
- Use `/kb` and a keyword to find a saved answer without leaving the keyboard.

## Common mistakes

- **Pressing Enter to add a new line.** In a chat reply, Enter sends. Use <kbd>Shift</kbd> + <kbd>Enter</kbd>.
- **Pressing Enter to add a session note.** Use <kbd>Ctrl</kbd> + <kbd>Enter</kbd>, or the plus button.
- **Typing `/kb` after other words.** The list only opens when `/kb` is the whole content of the box.
