A direct message (DM) is a private chat with one other person, or a small group, that does not need a channel name or a topic.

## Start a DM

1. In the channel list, click **New message**.
2. Pick one person for a one-to-one DM, or several for a group DM.
3. Click **Start**.

If you already have a DM with that exact set of people, Vircle CRM opens it instead of starting a new one — you will never end up with two separate DMs with the same person.

![The New message picker listing people to start a DM with](/help/img/direct-messages-01-new-dm.png)

## How a DM is different from a channel

- It has no name or topic — the other person's (or people's) name is shown instead.
- Membership is fixed when it is created. You cannot add or remove people from an existing DM.
- It does not appear in **Browse channels** and nobody can "join" it later.
- Every message you send in a DM notifies the other person, not only the ones where you @mention them — a DM is a direct conversation, so there is no need to @mention just to get their attention.
- Nobody can remove another person's message in a DM, not even the person who started it. See [Messaging and threads](/help/sembang/messaging-and-threads).

Everything else — reactions, pins, stars, threads, tasks, attachments, search — works exactly the same in a DM as in a channel.

## Mute a noisy DM

Open the DM, then its menu, then **Mute channel** (the same control channels use). See [Search, tasks and notifications](/help/sembang/search-notifications-and-access) for what muting does.

## Tips

- Starting a message with someone you already DM just reopens the same conversation — you do not need to search for the old one.
- Use a small group DM for a quick, informal back-and-forth. Create a proper channel instead if the conversation is going to grow or should be findable by others later.

## Common mistakes

- **Trying to add someone to an existing DM.** You cannot — start a new group DM that includes them instead.
- **Looking for a DM under Browse channels.** DMs never show up there.
