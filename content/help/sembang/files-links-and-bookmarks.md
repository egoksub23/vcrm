Every channel keeps its own running list of what has been shared in it — you do not have to scroll back through history to find a picture, a document or a link someone posted last week.

## The Files tab

Click the **Files** tab to see every file ever attached to a message in the channel, most recent first. A picture shows as a thumbnail — click it to view full size, or use the download button that appears on hover. Any other file type shows as a row with its name, size and who sent it.

![The Files tab showing a grid of image thumbnails and a file row](/help/img/files-links-and-bookmarks-01-files.png)

## The Links tab

Click the **Links** tab to see every URL anyone has pasted into a message, most recent first, along with who posted it and when. Where the link's page has a title, description or image, it unfurls into a small preview card — the same card you would see inline in the message itself. See [Messaging and threads](/help/sembang/messaging-and-threads) for how links unfurl as you type.

## Bookmarks

Bookmarks are a curated list for the channel, separate from Files and Links — use them for things worth surfacing on purpose (a shared doc, a dashboard, a recurring meeting link) rather than everything that happens to have been posted.

1. Click the **Bookmarks** tab.
2. Paste a **URL**, optionally give it a **label**, and click add.
3. Vircle CRM fetches a title, description and thumbnail where the page has them, the same as a link pasted into a message.

Any member can add a bookmark. The person who added it, a moderator, or an admin can remove it.

## Tips

- Bookmark a document once instead of re-pasting its link every time someone new joins the channel.
- Use the Files tab instead of asking "does anyone have that screenshot from last week?" in the channel.

## Common mistakes

- **Expecting every pasted link to unfurl.** A link only unfurls into a card when its page has a title or description to show — a plain URL with neither still appears, just without the card.
- **Looking for a bookmark in Files.** They are separate lists: Files/Links are everything shared automatically; Bookmarks are a deliberately curated set.
